# Support matrix

`rpg-benchmark support` is the machine-readable authority. Raw catalog
membership is not admission. The 29 definitions contain 37 task/terrain
combinations, not universal 29-by-3 or 37-by-3 modality support.

| Backend / task terrain | Structured | Hybrid | Image-only |
| --- | --- | --- | --- |
| Renderer C1/natural | scored | scored | interface/setup only; crafting unqualified |
| Renderer T01/natural, T02/flat, T03–T12/natural | scored | scored | unsupported except T05 below |
| Renderer T05/natural | scored | scored | visual-ui-v1; task-engineering only |
| Renderer N1/flat | unsupported | unsupported | inherited visual-motor-v1 scored |
| Headless 17 originals / 25 terrain combinations | inherited | unsupported | unsupported |
| All other combinations | unsupported | unsupported | unsupported |

There are 26 renderer structured/hybrid scored cells. Of the two image cells
with a scoring path, only N1/flat has capability admission. T05/image is
engineering-only. The shipped source-to-bundle path binds the renderer,
server and matching fixture helper; it does not provide a portable headless
binding. The headless interface and tests are retained, not newly qualified.

All 12 additions have structured/hybrid admission in the terrains shown.
T06 weapon choices are conditions of one task; T08 does not mandate use of
cover or the optional staff; T09 requires actual healing of another native
Group member. Visual inventory/dialogue primitives do not qualify whole
crafting, trade, skills, map-targeting or contract tasks.

## Evidence boundary

Qualification is engineering evidence, not model performance. Earlier family
and integrated native witnesses are inherited. For T12, hybrid qualification
includes actual native success. Structured qualification uses preserved
native contribution, death, living return and reward evidence plus corrected
scoring and chronological terminal/result replay. That is not a fresh native
structured win. The historical structured result remains false, interrupted
and transport-unknown; subsequent derived scores do not rewrite it.

The replay excludes later native evidence and checks that termination does
not occur early. Its timing fence still depends on uncertain same-host
clock mapping, not authoritative server/frame tick synchronization.

The runtime `qualification.json` is retained byte-for-byte as historical
build metadata, including pre-selection flags. Those flags are not the
current release status; see [PROVENANCE.md](PROVENANCE.md). Raw witnesses,
private controllers and historical run data are deliberately not published.
This source export runs no native qualification or model campaign.

Local setup refusals, variable-dt timing, GPU/system dependencies, external
assets, limited image coverage and lack of clean-machine validation remain.
Admission is not proof of platform independence or model capability.
