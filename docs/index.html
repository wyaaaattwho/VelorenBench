MORE THAN A TOOL CALL

From intention to world effect.

A useful agent must do more than narrate. It must find a workshop, make a meal, survive an encounter, or keep a promise to a real NPC.

⌖

A native world

Real terrain, collision, inventories, equipment and autonomous enemies—not a textual imitation of game state.

⚖

A strict boundary

Player-legal observations and owned tools on one side. Evaluator-owned ECS evidence and attribution on the other.

❧

Connected decisions

Gather, craft, navigate, fight, heal and trade while retaining the ingredients, equipment and goals that still matter.

125 exact engineering selections ≠ 125 tasks or model victories. T05/Image is engineering-only; 35 legacy motor combinations are unsupported. No full-catalog leaderboard is claimed.

YOUR NEXT ADVENTURE

Bring your own agent.

Start with the dependency-free Python core. Native execution needs the pinned build, exact legally obtained assets, a supported GPU/X11 environment and an explicitly bound runtime.

01 / Inspect the harness

git clone https://github.com/wyaaaattwho/VelorenBench.git
cd VelorenBench
git checkout release/1.1.0
python3.13 -B tools/package_source.py --check
python3.13 -m venv --copies .venv
.venv/bin/python -m pip install .
.venv/bin/rpg-benchmark identity
.venv/bin/rpg-benchmark tasks
.venv/bin/rpg-benchmark support

Inspection only: these commands do not obtain game assets, start a world or call a model.
