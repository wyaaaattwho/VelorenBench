# VelorenBench Python interface

Install from the repository root with Python >=3.13. The distribution is
`rpg-benchmark-harness`; the CLI is `rpg-benchmark`.

See the root README, API.md, SUPPORT.md and BUILD.md. Installed documentation
is also provided under `share/rpg-benchmark-harness`.
`identity`, `tasks`, `support` and `run --help` need no provider SDK or native
installation. Native execution requires an explicit hash-verified
`rpg-runtime/1` binding and external assets. Raw catalog size is not modality
admission; setup/synthetic checks are not model capability results.
